# Collision Shape validation (PRO-352)

Release candidate: 0.2.0, protocol 1.2. Publication requires owner approval.

Both Unity 6000.0.40f1 (development host) and 6000.4.6f1 (separate probe project) pass
142 EditMode tests, including the new ForgeCollisionTests. The 6000.0 host was not upgraded.

The collision fixtures are generated by Forge's Rust/WASM GLB writer. Tests verify:

- Four BoxColliders around a floor opening; one render mesh remains.
- A rigidbody sphere rests on the floor and a second falls through its opening.
- Five stair BoxColliders and one convex ramp MeshCollider.
- A rigidbody cube rests on the convex hull without PhysX cooking errors.
- A CharacterController climbs the 33.7 degree ramp and refuses the steeper scaled ramp at a 45 degree slope limit.
- Repeated pushes preserve prefab and hull mesh GUIDs.
- Switching from ramp to steps prunes the unused hull mesh asset.
- Sending no collision removes the owned child, preserving base-prefab user colliders and a variant's collider.

Physics tests run in isolated editor preview scenes and close them in finally blocks.
The existing transport, import, materials, animation and pruning tests also pass.

Before deploying the Forge client that pins 0.2.0, publish the matching package tag and release.
